# Video Downloader

Desktop app for video editors: download from YouTube, Instagram, Facebook, X,
Threads and TikTok at the exact resolution and codec you pick, convert to
files Premiere Pro and After Effects open (H.264 MP4), and
import straight into After Effects with the built-in panel.

Developed by Garv. A license key is required; ask Garv for one.

## Install

**Mac (Apple Silicon)** — open Terminal and paste:

```bash
curl -fsSL https://raw.githubusercontent.com/Garvvaiahnav/yt-downloader/main/install.sh | bash
```

**Windows (64-bit)** — open PowerShell and paste:

```powershell
irm https://raw.githubusercontent.com/Garvvaiahnav/yt-downloader/main/install.ps1 | iex
```

These avoid the "Apple could not verify" and SmartScreen warnings that a
browser download triggers. You can also download the installer from
[Releases](https://github.com/Garvvaiahnav/yt-downloader/releases/latest).

The app updates itself; every update is signature-checked before it installs.
